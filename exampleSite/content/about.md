## 你好，欢迎来到 Lumen 👋

这是 [Lumen 主题](https://github.com/nova02640/hugo-theme-lumen)的示例站点。Lumen 是一套为技术写作者打造的现代极简 Hugo 博客主题，核心原则只有四个字：**内容为王**。

## 本站技术栈

| 层次 | 选型 | 说明 |
| ---- | ---- | ---- |
| 静态生成 | Hugo ≥ 0.130 | 纯 Go 实现，毫秒级构建 |
| 样式方案 | 原生 CSS 变量 | 无 Tailwind，Hugo Pipes 压缩 |
| 交互脚本 | 原生 JS < 20KB | 渐进增强，无 JS 亦可浏览 |
| 检索 | Fuse.js | 客户端全文模糊匹配 |
| 评论 | Giscus（可选） | 基于 GitHub Discussions |
